# SPL
# 🌍 Climate Change Interactive Portfolio | Data-Driven Web Experience 🌦️🌠💫✨

Welcome to my **Climate Change Interactive Portfolio Website** — a creative frontend project designed to visually represent **climatic changes and their impact across different domains of study**.

This project focuses on combining **data visualization, storytelling, and interactive UI design** to make environmental change more engaging and understandable.

---

## 🎯 Project Vision🗽

The main idea behind this project is to transform complex climate concepts into a **visual and interactive web experience**, showcasing:

* 🌡️ Temperature variations over time
* 🌧️ Rainfall and weather pattern changes
* 🌪️ Extreme climate events
* 🌱 Environmental impact on ecosystems
* 🏙️ Human and urban impact of climate change

The goal is to make climate data feel more **visual, intuitive, and engaging** rather than purely theoretical.

---

## 🌦️ "Core Concept"🌠

This portfolio connects **climate change with different academic and real-world aspects**, such as:

* 📡 Environmental monitoring systems
* 🌾 Agriculture and ecosystem effects
* 🏭 Industrial and urban impact
* ⚡ Energy consumption patterns
* 🌊 Global environmental shifts

Each section of the website represents a **different dimension of climate impact**.!!
